    **Invite System (OBRA-02):**

    1. Create Zod validation `apps/web/lib/validations/invite.ts`:
       - `emailInviteSchema`: email (valid email), role (ADMIN|ENGENHEIRO|CLIENTE)

    2. Create Server Actions in `apps/web/lib/actions/invite.ts`:
       - `inviteByEmail(formData)`: Validate, create Invitation with nanoid(21) token, email set, role, obraId, empresaId from session, invitedBy from session, expiresAt = 7 days. Send email via Resend with invite link (`/invite/{token}`). React Email template with "Voce foi convidado" message, role info, CTA button.
       - `createShareableLink(formData)`: Create Invitation with nanoid(21) token, email=null, role, obraId (optional — null means empresa-level), empresaId, invitedBy, expiresAt = 30 days. Return the full URL.
       - `regenerateShareableLink(inviteId)`: Create new token (invalidates old), return new URL.
       - `acceptInvite(token)`: Find Invitation by token. Validate not expired, not used. If email is set, verify it matches session.user.email. If obraId is set, create ObraMember for that obra. If obraId is null (empresa-level invite), update User.empresaId to the invitation's empresaId.
         **CRITICAL — Session refresh after empresa-level invite:** After updating User.empresaId in the DB, the JWT still has the old `empresaId: null`. The middleware will redirect to onboarding unless the session is refreshed. To fix this:
         - Delete the session cookie using `cookies().delete('authjs.session-token')` (or `__Secure-authjs.session-token` in production) to invalidate the current JWT
         - Then redirect to `/api/auth/session` or `/login` to force Auth.js to issue a new JWT with the updated empresaId from the DB via the JWT callback
         - Alternatively, use `unstable_update()` from next-auth if available in the Auth.js v5 version being used — this triggers a JWT callback re-evaluation without requiring re-authentication
         - Mark invitation usedAt. Final redirect to /dashboard (after new session is established).
       - `listInvitations(obraId?)`: List pending (not used, not expired) invitations for the obra or empresa.
       - `revokeInvitation(id)`: Delete or mark expired.
       - Permission check: Only ADMIN and ENGENHEIRO can invite (per CONTEXT.md locked decision)
